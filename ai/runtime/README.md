# Runtime-артефакты для командной установки

Для установки без ручной настройки и без сетевой загрузки положите в каталог
`windows` два неизменённых upstream-артефакта:

- `bsl-indexer.exe` версии `0.69.0` или новее;
- `bsl-language-server-exec.jar`.

После этого из корня workspace `Kafka` достаточно выполнить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\ai\setup.ps1
```

Бинарники не являются исходным кодом этого репозитория. Их версия, происхождение и
контрольные суммы должны фиксироваться владельцем внутреннего поставочного комплекта.
